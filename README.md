### 🚀 Проекты

#### 🏍️ ENDURO — Telegram Mini App для проката эндуро-мотоциклов
Полноценное приложение для управления прокатом: запись клиентов, календарь загрузки, роли (владелец / менеджер / инструктор), финансовая статистика и аналитика, напоминания в Telegram, экспорт в Excel, двусторонняя синхронизация с Google Calendar. Работает в продакшене каждый день.

`React 19` · `TypeScript` · `Node.js` · `Fastify` · `Prisma` · `grammY` · `Telegram Mini Apps` · `Google Calendar API`
🔒 *Приватный репозиторий — покажу код и разберу архитектуру на собеседовании.*

#### 🛴 BusyFly — платформа кикшеринга (аренда самокатов)
Экосистема из Telegram Mini App менеджера и нескольких ботов: автозавершение поездок через Telegram и ВКонтакте, контроль задолженностей, антифрод, статусы самокатов. Собственная инфраструктура: автозапуск, сторожевые процессы, доступ через VPN-прокси. **Экономит ~120к ₽ в месяц.**

`Python` · `aiogram` · `Pyrogram` · `FastAPI` · `Telegram Mini Apps` · `VK API`
🔒 *Приватный репозиторий — продакшен действующего бизнеса.*
